# Frontend — CampusFind

This folder contains the static HTML, CSS, and JavaScript frontend. The Spring Boot app serves the mirrored files from `backend/src/main/resources/static/`.

When changing a page or stylesheet, copy the same file into the matching backend static-resource path before building the application. The main pages are `index.html`, `login.html`, `register.html`, `item.html`, `post.html`, `my-claims.html`, and `admin-claims.html`.
